Fetch the unresolved code review comments on the current PR and fix them yourself, directly.

Your job is to:

1. Fetch unresolved CR comments -
The 'gh unresolved' is a special command that fetches *ONLY* unresolved comments for a PR, to not overload the context.
Use the 'gh unresolved' command to fetch the CR comments, *ONLY* if it is not working correctly, use the github integration straight up.
'gh unresolved' - Prints the unresolved comments in the current branch's PR.
'gh unresolved {pr_id}' - Prints the unresolved comments in the given PR.

2. Fix the comments -
Plan, execute, and verify the changes yourself, directly, to fix the comments in the best way possible.
Do NOT delegate to another agent — you have all the tools you need; edit the files yourself.
After making the changes, run all tests and make sure they pass.

3. Commit and push -
Commit the changes / make sure they are already committed, then push them using Graphite (run `gt submit --stack`).
DO NOT push using regular git commands.
For more help using graphite commands, you can turn to the Graphite MCP.

4. Reply with the fix information to the comments -
After the changes were implemented successfully, use the github integration to reply to each comment with a concise summary of the fixes applied.
*CRITICAL* - At the end of each comment, place a signature with this exact template:
{comment text}

---
🤖 *Generated by **Claude***

5. Resolve the comments -
Finally, after replying, resolve each comment thread you addressed, using the github integration (or `gh api graphql` with the `resolveReviewThread` mutation if the integration doesn't expose it directly).
Only resolve threads you actually fixed and replied to — leave anything you couldn't address unresolved for a human to review.
Read the spec (if exists) for more context about the PR.
